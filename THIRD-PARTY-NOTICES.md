# Third-Party Notice Map

This candidate is packaged with Electron, Chromium, Node.js, Sharp, libvips, and their transitive components.

The packaged application preserves the notices supplied by those bodies, including:

- `LICENSE` and `LICENSES.chromium.html` beside the executable;
- dependency license files inside the packaged application resources where supplied;
- dependency identities and exact versions in `package.json` and `pnpm-lock.yaml` in the source body.

This map is not a substitute for the included license texts. Before public release, the candidate must receive a clean dependency-license inventory and a verification that every required notice survived packaging.

No third-party notice changes the pending status of Gwenithic-authored source, documentation, icons, or exemplar media.
